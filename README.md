# ARVY Showcase

Interactive showcase page for the ARVY thesis (PUP): Android-Monitored Reverse Vending Machine.

## Run on your computer

    npm install
    npm run dev

## Deploy on Render (Static Site)

1. Push this repo to GitHub.
2. In Render, click New > Static Site and pick this repo.
3. Build command: `npm install && npm run build`
4. Publish directory: `dist`
